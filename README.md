# 🪔 Diwali Sales Analysis

> 📊 Exploratory Data Analysis of Diwali Sales using Python

---

## 📌 About The Project

This project analyzes **Diwali sales data** to understand customer purchasing behavior, sales patterns, product categories, and customer demographics.

The goal is to extract meaningful insights from the dataset using Python and data analysis libraries.

---

## 🛠️ Tech Stack

🐍 **Python**
🐼 **Pandas**
🔢 **NumPy**
📊 **Matplotlib**
📈 **Seaborn**
📓 **Jupyter Notebook**

---

## 🔍 What I Analyzed

* 👥 Customer demographics
* 🛍️ Purchasing behavior
* 📦 Product categories
* 💰 Sales patterns
* 📊 Customer and product insights

## 🎯 Project Objective

To explore the Diwali sales dataset, perform data analysis, and identify useful patterns and insights from customer and sales information.

---

## 🚀 How to Use

1. Clone this repository.
2. Open `Diwali_Sales_Analysis.ipynb` in Jupyter Notebook.
3. Make sure the CSV file is in the same folder.
4. Run the notebook cells to view the analysis.
